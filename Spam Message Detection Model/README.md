### SMS Spam Detection Using Machine Learning

#### Project Description:

###### This project uses Machine Learning to classify SMS messages into two categories: Spam and Ham (Normal Messages).

###### The model uses the Naive Bayes algorithm to identify whether an entered message is spam or normal.

#### Technologies Used:

###### \* Python

###### \* Pandas

###### \* Scikit-learn

###### \* CountVectorizer

###### \* Multinomial Naive Bayes

#### Dataset:

###### The dataset contains SMS messages labelled as:

###### \* Ham: Normal messages

###### \* Spam: Unwanted or promotional messages

#### Machine Learning Workflow:

###### 1\. Load the dataset.

###### 2\. Separate messages and labels.

###### 3\. Split the dataset into training and testing data.

###### 4\. Convert text messages into numerical data using CountVectorizer.

###### 5\. Convert labels into numerical values.

###### 6\. Train the model using Multinomial Naive Bayes.

###### 7\. Evaluate the model using accuracy, confusion matrix and classification report.

###### 8\. Take user input and predict whether the message is spam or ham.
